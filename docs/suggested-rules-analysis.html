Suggested Rules Simulation Analysis

Last run: 2026-08-06

Outcome: add a guarded soft preference for Fizarre Drink: Chest Magnet and narrow Mister Bribe: Approval Lock's Harbinger safety window from three cases to two. Together they increase expected Retirement Chests and balanced utility in paired simulations. The measured death-rate difference includes zero, so the experiment does not establish a survival improvement or regression.

Method

The experiment used the built-in Justice dataset, uniform eligible-offer selection, the balanced utility preset, and the application's standard starting state: case 1, 5 Court Coins, 3 Popularity, 1 Mental Health, no dismissals, and no Retirement Chests. Each old/new comparison used the same integer seeds, beginning at zero. Reported confidence intervals are normal-approximation 95% intervals over paired per-seed differences.

Runs exercised the planner's future-policy simulation directly. The 12-case experiment matches the configured lookahead horizon; the 60-case experiment checks whether the effect persists beyond that horizon. This is model evidence, not a claim about the game's unknown real encounter distribution.

The refined rules improve the primary objective by 7.8% over 12 cases and 6.8% over 60 cases. The small reduction in mean ending case is a real tradeoff in the 60-case sample; balanced utility still improves because the additional chest yield outweighs it under the configured scoring weights.

Accepted changes

  • Chest Magnet: a +1 approval bias applies only when coins >= case_scale + harbinger_cost. The small bias recognizes the value of the next three Retirement Chester encounters, while the reserve condition and soft preference let rollout evidence reject unsafe purchases. Hard-requiring approval and a +5 bias were tested but rejected as unnecessarily aggressive.
  • Approval Lock: approving is forbidden only when harbinger_in is one or two. Acceptance is already the first of the three lock cases, so a lock taken three cases before Harbinger expires in time. With seed 123 and the default planner, case 2 changed from reject to approve while case 3 remained reject.

Alternatives considered

Screening covered every existing rule by leave-one-out ablation and tested additions for Humble Lesson, Crypto Drip, Student Loans, Kitchen Loan, Bored Bean's Loan, Ghost's Scare Permit, Above the Law, and Timmy Block. It also tested narrower Timmy, Promise Me, Reaper Contract, Vitality Trade, and Chest Heist policies. Delayed-loan requirements and hard Chest Magnet requirements reduced outcomes in screening. Existing rule removals were either neutral or showed chest/safety tradeoffs whose intervals did not support replacing the current guidance, so they were retained.

Simulation reliability correction

Before accepting the data result, two rollout edge cases were corrected: an encounter-triggered death is now returned as the terminal state, and constraints fall back when they leave no feasible action. Focused unit tests cover both cases. Candidate comparisons above were rerun only after these corrections, preventing dead-end policies from appearing safer than they are.

Limits and security

Results depend on the simulator's uniform encounter assumption and the uncertain probabilities documented in the data open-questions report. They should be rerun if observed encounter weights or unresolved outcome probabilities change. The new condition uses the existing whitelisted expression evaluator; it adds no dynamic evaluation or external input path.
